# Tipos de ausencia

La plataforma deja de funcionar solo como gestión de vacaciones y pasa a registrar ausencias en general.

## Tipos iniciales

- Vacaciones
- Cita médica
- Baja médica
- Ausencia justificada
- Asuntos propios
- Permiso retribuido
- Teletrabajo puntual
- Formación
- Otros

## Nuevo campo

Al crear una solicitud aparece:

- Tipo de ausencia
- Justificante opcional

## Criterio inicial

Para esta primera versión, todos los tipos siguen entrando en el flujo normal de registro/revisión para no romper la operativa actual.

Después se podrá ampliar con:

- tipos que solo comunican y no requieren aprobación,
- justificante obligatorio para bajas/citas médicas,
- estadísticas por tipo de ausencia,
- PDF específico según el tipo,
- exportación mensual para administración/nóminas.
