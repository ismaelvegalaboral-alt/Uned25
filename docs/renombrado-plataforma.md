# Renombrado de plataforma

Nombre anterior: `Vacaciones Pro`

Nombre nuevo: `Kalpae Gestión de Ausencias`

Motivo del cambio:

- Es más profesional y corporativo.
- No limita la herramienta únicamente a vacaciones.
- Encaja mejor con una plataforma interna de RRHH.
- Permite crecer hacia permisos, ausencias justificadas, bajas, asuntos propios o control documental.

Archivos tocados principalmente:

- `vacations/templates/vacations/base.html`
- `vacations/templates/vacations/login.html`
- `vacations/templates/vacations/dashboard.html`
- `vacations/pdf.py`
- `README.md`
- documentación asociada
