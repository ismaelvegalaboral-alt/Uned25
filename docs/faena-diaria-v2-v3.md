# Faena diaria v2/v3

## Añadido en esta versión

### V2
- Vista panel agrupada por cliente/obra.
- Copiar faena de un día a otro.
- Editar líneas.
- Eliminar líneas.
- Editar estados.
- Eliminar estados.
- Exportar CSV compatible con Excel.
- Publicar/ocultar faena.

### V3
- Crear parte personal desde una línea de faena.
- Crear albarán cliente desde una línea de faena.
- Pre-rellenado automático de cliente, obra, máquina, camión, horas, viajes y observaciones cuando se llega desde la faena.
