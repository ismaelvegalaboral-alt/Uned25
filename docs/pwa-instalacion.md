# PWA - instalación como app

La plataforma queda preparada para instalarse como app desde:

https://ausencias.kalpae.es

## Android / Chrome

1. Abrir la plataforma.
2. Menú de tres puntos.
3. Instalar app o Añadir a pantalla de inicio.

## iPhone / Safari

1. Abrir la plataforma.
2. Compartir.
3. Añadir a pantalla de inicio.
