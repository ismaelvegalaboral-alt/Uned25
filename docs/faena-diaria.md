# Faena diaria

Primera versión del módulo de planificación diaria.

## Qué permite

- Crear una faena por fecha.
- Añadir líneas de trabajo con cliente, obra/zona, máquina, camión, trabajador, horas, viajes y observaciones.
- Añadir estados de disponibilidad: vacaciones, asuntos propios, baja, reconocimiento, mantenimiento, taller/ITV, formación, parado, subcontratado/alquilado y varios.
- Publicar la faena para que los trabajadores vean sus asignaciones.

## URLs

- `/faena/`
- `/faena/nueva/`
- `/faena/<id>/`
- `/faena/<id>/linea/nueva/`
- `/faena/<id>/estado/nuevo/`
- `/mi-faena/`
