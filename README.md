# Uned25 · Campus Digital de Acceso

Plataforma conceptual para preparar la prueba de acceso a la universidad:

- Biblioteca colaborativa de apuntes, libros y exámenes resueltos.
- Panel inteligente que genera planes de estudio personalizados.
- Herramientas interactivas para crear resúmenes, flashcards y quizzes.
- Comunidad con mentorías, retos gamificados y soporte entre estudiantes.

## Desarrollo local

1. Clona el repositorio y entra en la carpeta `Uned25`.
2. Lanza un servidor estático (`python -m http.server 8000`).
3. Abre `http://localhost:8000/index.html` en tu navegador.
